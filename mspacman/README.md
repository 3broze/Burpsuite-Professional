# 🕹️ Ms. Web-Man - Arcade Browser Game

An authentic, fully-featured arcade browser game inspired by **Ms. Pac-Man**, built with HTML5 Canvas, Vanilla JavaScript, and the Web Audio API.

## Features
- **Classic Arcade Gameplay**: Navigate the neon maze, eat all dots, avoid 4 unique ghosts (Blinky, Pinky, Inky, Sue), and collect energizers to turn ghosts vulnerable!
- **Dynamic Fruit Bonuses**: Collect bouncing bonus fruits (Cherries, Strawberries, Peaches, Pretzels, etc.) for bonus points.
- **Procedural 8-Bit Audio**: Fully synthesized sound effects using the Web Audio API (start jingle, waka eating, siren, energizer alarm, ghost eating, fruit chimes, and death tune).
- **Arcade CRT Aesthetic**: Simulated CRT scanlines toggle, pixel-art scaling, high-score saving via `localStorage`, and responsive touch controls for mobile devices.
- **Controls**:
  - **Desktop**: Arrow keys or `WASD` to move, `Space` to pause/start.
  - **Mobile**: On-screen touch D-pad.

## How to Play
Open `index.html` in any modern web browser or serve it via a local static server (e.g. `npx serve mspacman` or Python's `http.server`).
