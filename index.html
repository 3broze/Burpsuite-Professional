Installation

Pick your platform

Copy the commands below. Everything runs from the repository root.

1

Install

Debian / Ubuntu / Kali and derivatives:

sudo apt update && sudo apt install -y wget && \ wget -qO- https://raw.githubusercontent.com/xiv3r/Burpsuite-Professional/main/install.sh | sudo bash
2

Run

burpsuitepro
3

Update (optional)

cd && sudo rm -rf Burpsuite-Professional && \ wget -qO- https://raw.githubusercontent.com/xiv3r/Burpsuite-Professional/refs/heads/main/update.sh | sudo bash
4

Wrong Java version?

Select the default OpenJDK runtime:

sudo update-alternatives --config java
Desktop launcher (XFCE): right-click the desktop → Create Launcher → name it “Burpsuite Professional”, set the command to burpsuitepro, and pick the Burp Suite icon.
1

Add the flake to your inputs

# flake.nix { inputs = { burpsuitepro = { type = "github"; owner = "xiv3r"; repo = "Burpsuite-Professional"; inputs.nixpkgs.follows = "nixpkgs"; }; }; }
2

Install the package (NixOS module)

{ inputs, ... }: { environment.systemPackages = [ inputs.burpsuitepro.packages.${system}.default ]; }
3

…or with home-manager

{ inputs, ... }: { home.packages = [ inputs.burpsuitepro.packages.${system}.default ]; }
Note: loader.jar is symlinked next to burpsuite.jar so Burp recognises the license keys. The loader command is available from the terminal only.
1

Prepare the folder

Create C:\Burp, then download the repo ZIP and extract its contents into that folder.

2

Allow script execution

Open PowerShell as administrator:

Set-ExecutionPolicy -ExecutionPolicy bypass -Scope process
3

Run the installer

cd C:\Burp .\install.ps1
4

Create the shortcut

  • Right-click Burp-Suite-Pro.vbs → Shortcut tab → Change Icon
  • Choose C:\Burp\burp_suite.ico
  • Copy the shortcut to your Desktop

For a Start Menu entry, copy Burp-Suite-Pro.vbs to:

C:\ProgramData\Microsoft\Windows\Start Menu\Programs\
1

Install dependencies with Homebrew

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)" brew install git openjdk@17
2

Run the installation script

Clones the repo, downloads the JAR, and starts the key generator and Burp Suite.

curl -fsSL https://raw.githubusercontent.com/xiv3r/Burpsuite-Professional/main/install_macos.sh | bash
3

Install the burp shortcut

chmod +x burp sudo cp burp /usr/local/bin/burp
Heads-up: the generated script uses $(pwd), so run burp from the Burpsuite-Professional directory containing loader.jar and the Burp JAR — or replace $(pwd) with absolute paths for true global use.

Activation

Setting up the license

The loader window and Burp's manual activation dialog exchange two keys.

Copy the license

Grab the license string from the loader window.

Paste into Burp

Burp Suite → Manual activation → paste the license.

Request key → loader

Copy Burp's activation request key into the loader's request field.

Response key → Burp

Copy the loader's response key back into Burp to finish.

FAQ

Common questions

Which Java version do I need?

The Linux script installs openjdk-21-jre; the macOS path uses openjdk@17. If Burp fails to start, switch your default runtime with sudo update-alternatives --config java.

Burp starts but the license won't activate

Make sure loader.jar is passed as the -javaagent and sits next to the Burp JAR. On NixOS it is symlinked automatically. Re-run the manual activation flow described above.

How do I launch it after installing on Linux?

The installer writes a burpsuitepro script to /bin, so just run burpsuitepro from any terminal, or wire it to a desktop launcher.

Where does the Burp Suite JAR come from?

The scripts fetch burpsuite_pro_v<version>.jar from this repository's GitHub Releases. Change the version variable in install.sh to pin a different build.

Can I contribute or report an issue?

Yes — open an issue or pull request on the GitHub repository.
